```

 tooltip: "Ourobask · วันนี้ 4 งาน · เกินกำหนด 1"

 คลิกซ้าย → O4                        คลิกขวา:
                                       ＋ เพิ่มงานด่วน              Ctrl+Alt+N

                                       ▭ เปิด Ourobask
                                      ────────────────────
                                       📌 โน้ตบนหน้าจอ ▸   แสดงทั้งหมด · ซ่อนทั้งหมด
                                       ⏸ งดแจ้งเตือน ▸     1 ชม. · ถึงพรุ่งนี้ 08:00 · จนกว่าจะเปิดเอง
```

- ปิด ✕ หน้าต่างหลัก = ซ่อนลงถาด · ครั้งแรก: toast "Ourobask ยังทำงานอยู่ที่ถาด เพื่อเตือนงานให้คุณ · ตั้งค่าได้ที่ ⚙ › PC"

- เปิดพร้อม Windows: ถามครั้งเดียวหลังตั้งเตือนงานแรกบน PC (ช่วงเวลาที่ผู้ใช้เข้าใจว่าทำไมต้องเปิด) — ไม่ถามตอนเปิดแอปครั้งแรก

## 3. O2 โน้ตบนหน้าจอ

```
 ┌───────────────────────────────┐   240×160 · ย่อได้ถึง 160×96 · ไร้กรอบ · ลากที่หัว
 │▍ส่งรายงานลูกค้า          📌 ✕ │   ▍ แถบซ้าย 4px = ความสำคัญ (ปกติ: ไม่มี · สำคัญ: accent · ด่วนมาก: danger + ⚠)
 │  วันนี้ 17:00 · ด่วนมาก ⚠      │   เกินกำหนด = ข้อความ "เกินกำหนด" + ⚠ ไม่ใช่แค่สีแดง
 │  ☐ แนบไฟล์สรุป                 │   เช็กลิสต์ `- [ ]` ใน notes (v1 · Z7)
 │  ☐ โทรยืนยัน                   │
 │  ─────────────────────────── │
 │  [✓ เสร็จ]  [⏰ เลื่อน ▾]  [⋯]  │   แสดงเมื่อ hover **หรือ** โฟกัสด้วยคีย์บอร์ด
 └───────────────────────────────┘
 📌 = ปักบนสุด (เปิด: ไอคอนทึบ, tooltip "ปักไว้บนสุด")   ✕ = ซ่อนโน้ต — งานไม่ถูกลบ ไม่มีวันลบจาก ✕
 [⋯] = เปิดใน Ourobask · ส่งให้ Z.I.Z · เปลี่ยนสี · เลิกปัก
```
- สร้าง: เมนูงาน/โน้ต "ปักเป็นโน้ตบนหน้าจอ" · ถาด ▸ โน้ตบนหน้าจอ · ปุ่ม 📌 ในรายการย่อ
- สีพื้น = `Color.lerp(p.surface, taskColor, 0.18)` · **ตัวอักษร = `t1` เสมอ** → contrast มาจาก token ไม่ขึ้นกับสีที่ผู้ใช้เลือก (`T4-C` §5.3)
- งานเสร็จ (จากที่ไหนก็ตาม) → โน้ตขีดฆ่า 2 วินาทีแล้วปิด · `desk_pins` ถูกลบ · งานถูกลบ/ย้ายไปประวัติ → โน้ตปิด
- เพดาน **8 ใบพร้อมกัน** (หนึ่งใบ = หนึ่ง Flutter engine ≈ RAM หลายสิบ MB [K ต้องวัด S2]) · ใบที่ 9: "แสดงได้สูงสุด 8 ใบ — ซ่อนใบไหน?" ❓ → [Grill Q3](./07-grill-me.md)
- ตำแหน่ง/ขนาด/จอ/ปักบนสุด จำใน `desk_pins` · จอถูกถอด → ดึงกลับเข้าพื้นที่ทำงานของจอหลัก
- **ไม่แย่งโฟกัส** ตอนโผล่ (เทียบ `SW_SHOWNOACTIVATE`) · ข้าม taskbar · แต่ยังอยู่ใน Alt+Tab และมีชื่อหน้าต่าง "Ourobask — ส่งรายงานลูกค้า" ให้ screen reader อ่านได้

## 4. O3 แจ้งเตือน + O3a การ์ดปลุก

```
 ┌ Ourobask ─────────────────────────────── ✕ ┐   Reminder.isAlarm = false
 │ ⏰ ส่งรายงานลูกค้า                            │   ไป Action Center ตามปกติ
 │ ครบกำหนดใน 15 นาที · 17:00                    │
 │ [เสร็จแล้ว]  [เลื่อน 10 นาที]  [เปิด]           │
 └──────────────────────────────────────────┘

 ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓   Reminder.isAlarm = true — การ์ดของแอป always-on-top
 ┃  ⏰ ปลุก · 17:00                              ┃   ขอโฟกัสได้ (ตัวเดียวที่ทำได้ · ปิดได้ในตั้งค่า)
 ┃  ส่งรายงานลูกค้า                              ┃   เสียง .wav วนจนกด
 ┃  [ ✓ เสร็จแล้ว ]  [ เลื่อน ▾ ]  [ ปิดเสียง ]    ┃   Enter = เสร็จ · S = เลื่อน · Esc = ปิดเสียง
 ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
 เลื่อน ▾ = 10 นาที · 1 ชม. · พรุ่งนี้ 08:00 · เลือกเวลา… (v1)
```
- กิจวัตร: ขึ้นต้น "กิจวัตร ·" และมีแค่ [ทำแล้ว] [เปิด] (ไม่มีเลื่อน — กิจวัตรวนอยู่แล้ว) · แผนเก็บเงินเควส: "ถึงรอบเก็บเงิน ฿500.00" (ข้อความเดิมของ `_bodyForRoutine`)
- ถ้า spike S1 พบว่าแจ้งเตือนของ Windows ใส่ปุ่มไม่ได้แบบไม่แพ็ก MSIX → ใช้การ์ดของแอปแบบเล็ก (มุมขวาล่าง, หายเองใน 8 วินาที) แทนสำหรับทุกการเตือน
- เปิดแอปหลังปิดไป: แจ้งเตือนเดียว "พลาดการเตือน 3 รายการ ระหว่าง 14:00–17:30 [ดู]" → [ดู] เปิดรายการย่อแถบ "พลาด"

## 5. O4 รายการย่อ + O5 เพิ่มงานด่วน

```
┌ วันนี้ · ส. 18 ต.ค. 2569 ─────────── 📌 ⤢ ┐   📌 = ไม่ปิดเมื่อคลิกนอก · ⤢ = เปิดหน้าต่างเต็ม
│ ＋ เพิ่มงาน… เช่น "ส่งรายงาน พรุ่งนี้ 9:00 !ด่วน" │
│ ── ⚠ เกินกำหนด (1) ─────────────────── │
│ ☐ ▍ชำระค่าไฟ                 เมื่อวาน      │
│ ── วันนี้ (3) ────────────────────── │
│ ☐ ▍ส่งรายงานลูกค้า           17:00  📌     │   📌 = มีโน้ตบนจอ
│ ☐ ▍ซื้อของใช้               ทั้งวัน         │
│ ◷  ▍ร่างสัญญา  · Z.I.Z รอตรวจ  [ดู]        │   chip สถานะ agent (ข้อความ + ไอคอน)
│ ── กิจวัตรวันนี้ ──────────────────── │
│ ☑ ▍ออกกำลังกาย               07:00         │
│ ── เควส ──────────────────────────── │
│ 🎯 ออมเงินซื้อโน้ตบุ๊ก   ฿12,400 / 35,000   │
│ [⇢ ส่งงานค้างให้ Z.I.Z]          ประวัติ ›   │
└──────────────────────────────────────────┘
```
- กลุ่มมาจาก `AppState.homeSections()` (bucket เดิม) — **ไม่มีโมเดลใหม่** · ป้ายกลุ่มเป็นข้อความ + ไอคอน · สีแถบจาก token:
  เกินกำหนด `danger` · วันนี้ `warn` · ใกล้ถึง `info` · อื่น ๆ ไม่มีสี (แทนสี hard-code `#E76F51 #E9A319 #43A047` ใน `home_page.dart` เฉพาะบน PC)
- ติ๊กเสร็จ = ขีดฆ่า + toast "เสร็จแล้ว · เลิกทำ" 5 วินาที (ไม่มี dialog ยืนยัน) · `Esc`/คลิกนอก = ปิด (ถ้าไม่ปัก)
- ปี พ.ศ. ตามตั้งค่าเดิม `buddhistYear`

**เพิ่มงานด่วน (O5)**: popup กว้าง 480 กลางจอที่เมาส์อยู่ · พิมพ์แล้วคำที่เข้าใจขึ้นเป็น chip ใต้ช่อง **ก่อน** Enter:
```
 ┌──────────────────────────────────────────────┐
 │ ส่งรายงาน พรุ่งนี้ 9:00 !ด่วน                    │
 │ [📅 อา. 19 ต.ค. 09:00 ✕] [⚑ ด่วนมาก ✕] [📁 ไม่มีโฟลเดอร์ ▾] │
 │ Enter = บันทึก · Shift+Enter = บันทึกแล้วเปิดแก้ไข · Esc = ยกเลิก │
 └──────────────────────────────────────────────┘
```
- ✕ บน chip = คำนั้นกลับเป็นข้อความในชื่อ (กันวันผิดแบบเงียบ — Todoist O7)
- MVP เข้าใจ: `วันนี้ พรุ่งนี้ มะรืน` · `จันทร์…อาทิตย์` (ครั้งถัดไป) · `HH:MM` · `เช้า/บ่าย/เย็น N` · `!สำคัญ !ด่วน` · `#ชื่อโฟลเดอร์` ❓ → [Grill Q7](./07-grill-me.md)

## 6. O7 ส่งงานให้ Z.I.Z + แผงตรวจ

**ส่ง** (เมนูงาน "ให้ Z.I.Z ช่วย…", ปุ่มท้ายรายการย่อ, ถาด):
```
 ให้ Z.I.Z ช่วย · ส่งรายงานลูกค้า
 ◉ แตกเป็นเช็กลิสต์ + เสนอลำดับทำ      ○ ร่างข้อความ/เอกสารที่งานนี้ต้องใช้
 ○ หางานที่ซ้ำหรือชนกัน                ○ คำสั่งเอง… [________________]
 ⓘ Z.I.Z จะเห็น: ชื่อ · รายละเอียด · กำหนด · โฟลเดอร์ — ไม่เห็นเสียง/ยอดเงินเควส (เว้นแต่อนุญาตในตั้งค่า)
                                                     [ยกเลิก]  [ส่งให้ Z.I.Z]
```
- ส่ง = `agent_state = queued` เท่านั้น — **Ourobask ไม่เรียก Z.I.Z เอง** (Z.I.Z/agent เป็นฝ่ายมาดึงงานผ่าน MCP) ·
  ถ้า Z.I.Z ติดตั้งอยู่: ปุ่มรองในการ์ด "เปิด Z.I.Z" (deep link ผ่าน Hub, ECO-C2) · ไม่มี: "ติดตั้ง Z.I.Z ผ่าน Hub"
- chip บนงาน: `◷ รอ Z.I.Z` (queued) · `⟲ Z.I.Z กำลังทำ` (claimed) · `◉ รอตรวจ` (needs_review, สี info) · `⚠ Z.I.Z ทำไม่สำเร็จ [ลองใหม่]` (failed, สี warn)

**แผงตรวจ** (แผงขวาของหน้าต่างเต็ม — ไม่ใช่ modal ที่บล็อก ตาม UX-LAYOUT):
```
 ┌ ผลงานจาก Z.I.Z · ส่งรายงานลูกค้า ─────────────── ✕ ┐
 │ ผลลัพธ์                                             │
 │  ## ลำดับที่แนะนำ  1) รวบรวมตัวเลข … (Markdown)       │
 │ การเปลี่ยนแปลงที่เสนอ (4)            [เลือกทั้งหมด]   │
 │  ☑ เพิ่มเช็กลิสต์ 3 ข้อในรายละเอียด                  │
 │  ☑ เลื่อนกำหนด 18 ต.ค. 17:00 → 19 ต.ค. 12:00        │   แต่ละข้อขยายดู before/after ได้
 │  ☑ งานใหม่ "ขอตัวเลขยอดขายจากฝ่ายบัญชี" (โฟลเดอร์เดิม) │
 │  ☐ เปลี่ยนความสำคัญ ปกติ → ด่วนมาก                    │
 │ ⓘ ก่อนใช้ จะเก็บสำเนาข้อมูลไว้ ย้อนกลับได้ใน ⚙ › AI    │
 │                         [ไม่รับทั้งหมด]  [ใช้ 3 รายการ] │
 └─────────────────────────────────────────────────────┘
```
- หลังใช้: toast "ใช้ 3 การเปลี่ยนแปลงจาก Z.I.Z · เลิกทำ" · งานกลับเป็น `none` · ผู้ใช้ติ๊ก "เสร็จ" เองเมื่อพอใจ
- **หน้าขอสิทธิ์ครั้งแรก** (ECO-S1, `T4-C` §1.4): modal `sm` "Claude Code (ผ่าน Z.I.Z) ขออ่านงานใน Ourobask" ·
  [อนุญาตครั้งนี้] [อนุญาตจนปิดแอป] [ไม่] · ชื่อ client แสดงเป็นป้าย (ปลอมได้ — ECO-S1) · ครั้งแรกบอก "ข้อมูลจะถูกส่งให้ผู้ให้บริการโมเดลของ agent ที่คุณใช้" (ECO-S5)
- ⚙ › AI: รายการสิทธิ์ (เพิกถอนได้) · audit log ล่าสุด 200 รายการ · "ย้อนการเปลี่ยนแปลงจาก AI ครั้งนี้" ต่อ snapshot (ECO-S3)
