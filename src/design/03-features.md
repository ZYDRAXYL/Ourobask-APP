ลำดับ: **MVP** = Ourobask PC รุ่นแรกที่เข้า Eco · **v1** = รุ่นเต็มของ Eco v1 · **later** = หลัง v1
ที่มา: `T2-C` = `Zydraxyl-HUB/Design/eco/research/T2-C-features.md` §4 (รหัส O1–O21) · `T3-C` / `T4-C` อ้างหัวข้อ

เจตนาเจ้าของ 4 ข้อ → ฟีเจอร์ที่ตอบ:

## 5. สิ่งที่ตั้งใจไม่ทำ

| ไม่ทำ | เหตุผล |
|---|---|
| นำเข้า issue จาก GitHub/Jira, เขียน worklog กลับ Jira (O2, O3) | ไม่อยู่ในเจตนาเจ้าของ · O3 แหล่งอ่อน |
| sync ผ่านบัญชี/คลาวด์ของเราเอง (O13) | Eco ไม่มีบัญชี (แนว DDX Transfer) |
| ให้ Z.I.Z ลบข้อมูลแบบ batch / ล้างทั้งหมด / นำเข้าแบบเขียนทับ ผ่าน MCP | ECO-S2 (`eco_delete` ยืนยันทุกครั้ง) · `T3-C` §4.6 "Not exposed" |
| ตัวอัปเดตในแอปบน Windows ที่ดาวน์โหลดเอง | หน้าที่ของ Hub (ECO-K*) — แอปแค่บอกว่ามีรุ่นใหม่ |
